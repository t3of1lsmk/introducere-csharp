Primul program in C#

Scrie un cod C# simplu si apasa pe „Ruleaza” pentru a vedea ce se afiseaza in consola.

  • using System; -> adauga functiile de baza.
  • Console.WriteLine(...) -> afiseaza textul in consola.
  • class Program -> defineste programul principal.
  • Main() -> este punctul de pornire al programului.
